## 📖 เกี่ยวกับโปรเจค

KX SMART Play เป็นพื้นที่ที่ออกแบบมาเพื่อเสริมสร้างทักษะแห่งศตวรรษที่ 21 และการค้นพบตนเองของนักนวัตกรรุ่นเยาว์ พัฒนาโดย **มหาวิทยาลัยเทคโนโลยีพระจอมเกล้าธนบุรี (มจธ.)**

เว็บไซต์นี้สร้างขึ้นเพื่อ:
- 📌 แนะนำภาพรวมของ KX SMART Play
- 📚 นำเสนอหลักสูตรและเนื้อหาการเรียนรู้
- 👨‍👩‍👧‍👦 แสดงรีวิวจากผู้ปกครองและนักเรียน
- 📞 ให้ข้อมูลติดต่อสำหรับผู้สนใจ

## ✨ คุณสมบัติเด่น

| Feature | Description |
|---------|-------------|
| 🌍 **รองรับ 3 ภาษา** | ไทย, อังกฤษ, ญี่ปุ่น - สลับภาษาได้ทันที |
| 📱 **Responsive Design** | รองรับทุกขนาดหน้าจอ (Desktop, Tablet, Mobile) |
| 🎠 **Image Slider** | แสดงภาพกิจกรรมด้วย Swiper.js |
| 🎬 **วิดีโอบรรยากาศ** | วิดีโอแนะนำบรรยากาศภายในศูนย์ |
| ⚡ **Loading Animation** | หน้าจอ Loading สวยงาม |
| 🍔 **Hamburger Menu** | เมนูสำหรับหน้าจอมือถือ |

## 🛠️ เทคโนโลยีที่ใช้

- **HTML5** - โครงสร้างหน้าเว็บ
- **CSS3** - สไตล์และ Animation
- **JavaScript** - ฟังก์ชันการทำงาน
- **jQuery** - DOM manipulation
- **Swiper.js** - Image carousel/slider
- **Google Fonts** - Inter, M PLUS 2, Noto Sans JP

## 📁 โครงสร้างโปรเจค

```
KXWebsite/
├── index.html          # หน้าหลักของเว็บไซต์
├── style.css           # สไตล์หลัก
├── reset.css           # CSS reset
├── main.js             # JavaScript หลัก (รวมระบบแปลภาษา)
├── fonts/              # ไฟล์ฟอนต์
├── img/                # รูปภาพทั้งหมด
├── smart play.mp4      # วิดีโอแนะนำ
└── README.md           # ไฟล์นี้
```

## 🚀 วิธีการใช้งาน

### เปิดเว็บไซต์
```bash
# 1. Clone repository
git clone https://github.com/leequeRz/KXWebsite.git

# 2. เปิดไฟล์ index.html ในเบราว์เซอร์
# หรือใช้ Live Server extension ใน VS Code
```

### รันด้วย Live Server (แนะนำ)
1. ติดตั้ง **Live Server** extension ใน VS Code
2. คลิกขวาที่ `index.html`
3. เลือก "Open with Live Server"
